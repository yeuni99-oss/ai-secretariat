# AI 비서실 v3 — 추가 결제 없는 운영형 시제품

## 사용하기
1. 압축을 풀고 `index.html`을 브라우저에서 열면 **로컬 모드**로 바로 사용할 수 있습니다. 브라우저 저장소를 삭제하면 기록이 없어질 수 있으므로 `전체 기록 백업(JSON)`을 주기적으로 사용하세요.
2. 모바일·PC에서 같은 기록을 보려면 GitHub Pages와 Supabase 무료 프로젝트를 **직접 개설**해야 합니다. 두 서비스 모두 무료 제공량·이용 조건이 변할 수 있습니다.
3. Supabase SQL Editor에서 `supabase.sql`을 **최초 1회만** 실행합니다. `config.js`에 프로젝트 URL과 **publishable/anon 키만** 넣습니다. `service_role` 또는 비밀 키를 절대 넣지 마세요.
4. GitHub Pages로 HTTPS 배포한 뒤 Supabase Auth의 Site URL / Redirect URL을 배포 URL로 설정합니다. 이메일 확인 후 로그인합니다.
5. Supabase 클라우드 모드에서 여러 기기를 동시에 수정하지 마세요. 현재는 마지막 저장 우선 방식이며 충돌 해결 기능이 없습니다.

## 비용 제한 원칙
- 이 시제품에는 유료 OpenAI API, 유료 호스팅, 자동 과금 기능이 없습니다.
- GitHub Pages 및 Supabase Free의 무료 제공량 안에서만 운영하세요. 초과 시 서비스가 제한·일시 중지될 수 있습니다. 카드 등록이나 유료 업그레이드는 하지 마세요.
- Google Drive는 현재 **결과물 링크만** 연결할 수 있습니다. 파일 자동 검색·동기화는 구현하지 않았습니다.
- AI 직원들은 아직 실제로 회의하거나 문서를 작성하지 않습니다. 업무일지·회의록은 수동 입력 방식입니다.
- 로컬 모드에서는 다른 기기로 자동 동기화되지 않습니다. JSON 백업을 이용해 옮길 수 있습니다.
- 무료 Supabase의 프로젝트 휴면·데이터 보존 정책을 확인하고 백업을 유지하세요.

## 개인정보/보안
- 공개 GitHub 저장소에는 업무 자료, 비밀번호, 서비스 비밀 키를 올리지 마세요.
- 브라우저 코드와 `config.js`는 누구나 열람할 수 있으므로 공개 가능한 publishable/anon 키만 사용하세요.
- `supabase.sql`은 사용자별 접근을 제한하는 RLS 정책을 포함합니다.
- 현재 시제품은 개인용 테스트이며 실제 업무의 민감한 자료를 올리기 전에 별도 보안 점검이 필요합니다.
